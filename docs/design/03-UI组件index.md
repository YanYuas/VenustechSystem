**色彩纪律（硬验收）**：
- 语义色（mint/butter/sky/strawberry/gold）**只表达状态**，不当装饰色；装饰只用 启明粉 + 淡紫 + 奶油灰阶
- 全库只出现上述token，任何组件**不得写死token外色值**——grep `#` 即可检查
- 主文字用`--text-hi`（暖棕黑，治愈感来源），不用纯黑`#000`
- 主按钮/关键指标/焦点任务只用`--primary`启明粉
- 治愈感不牺牲清晰度：正文对比度≥4.5:1，关键数值高对比
- `--gold`星尘金是启明星专属点缀色，**仅用于**灵感气泡、成就徽章、桌宠高光、星级评分，不滥用

| `--radius-pill` | 999px | 胶囊按钮/标签/头像 |

**投影**（糖果软影，粉调非冷灰）：
| Token | 值 | 场景 |
|-------|-----|------|
| `--shadow-card` | `0 6px 16px rgba(255,143,163,.18)` | 普通卡片 |
| `--shadow-raise` | `0 12px 32px rgba(255,143,163,.28)` | 浮层/弹窗/下拉 |
| `--glow` | `0 0 20px rgba(255,143,163,.30)` | 关键指标/焦点任务/主按钮辉光 |
| `--glow-gold` | `0 0 16px rgba(245,200,66,.35)` | 灵感/成就/星尘金辉光 |

**奶油底纹**：页面底 = 奶油色 + 极淡圆点波点（`radial-gradient` 1px圆点，5%启明粉不透明度），像草莓牛奶质感。首页英雄区加顶部径向渐变光晕（启明粉10%→透明420px）。

**密度**：放松不挤——卡片内间距16px基线，表格行高40px，侧边栏项高44px，留出呼吸感（治愈≠信息焦虑）。

### 0.4 动效系统（"活"的来源）

动效用**甜点店拟人语言**（软弹簧、呼吸、漂浮、微微摇摆），200~400ms内完成，不打扰读数。

| 动效 | Token/实现 | 场景 | 时长 |
|------|-----------|------|------|
| **咕嘟弹入**（招牌） | `@keyframes gudu` + `--ease-spring` | 面板/卡片/消息/弹窗入场 | 450ms |
| **数字翻滚** | `tabular-nums` + transform位移 | 统计卡数值变化 | 300ms |
| **图表绘制** | SVG `stroke-dashoffset` / 高度增长 | 图表载入，错峰`--i*80ms` | 600ms |
| **云朵漂浮** | `@keyframes floaty` | 空状态插画/装饰云 | 6s循环 |
| **状态呼吸灯** | `@keyframes breathe` | 在线/进行中/告警圆点 | mint 2s/butter 1.2s/straw 700ms |
| **流式打字机** | 光标闪烁`@keyframes blink` | AI回复/灵感生成 | 光标1s |
| **果冻按钮** | `scale(.96)→1` spring | 按钮按下回弹 | 250ms |
| **卡片悬浮** | `translateY(-3px)` + 阴影加深 | hover卡片 | 300ms |
| **图标摇摆** | `rotate(±4°)` | hover图标/通知铃 | 1s |
| **星尘闪烁** | `opacity+scale` | 灵感/成就出现时 | 800ms |
| **出入场** | 咕嘟弹入 / 150ms淡出下沉 | Toast/Modal/Drawer | 入450ms/出150ms |

**缓动函数**：
- `--ease-spring: cubic-bezier(.34,1.56,.64,1)` —— 软弹簧（咕嘟弹入/按钮回弹）
- `--ease-soft: cubic-bezier(.22,1,.36,1)` —— 柔和（颜色/阴影/位移过渡）

**性能降级（硬约束）**：
- 全部动效走token；图表动画**只对视口内元素跑**（IntersectionObserver）
- 命中`prefers-reduced-motion`全部关闭（云朵停飘、呼吸灯变静态点、弹入变淡入）
- 元素密集时自动降采样；目标同屏60fps不掉帧

### 0.5 图标与插画语言

**图标**：
- 一律16/20/24px **线性圆头图标**（2px描边，`stroke-linecap: round`，`stroke-linejoin: round`）
- 内联SVG，`stroke: currentColor`跟随token
- 图标库：Lucide（圆头变体）或自绘，统一2px描边

**插画**（启明星专属语言）：
- 主题：**"星尘/云朵/小灯塔/瞌睡的小猫头鹰/糖果/茶杯/启明星"**
- 线稿黑白 + 局部淡紫/启明粉/星尘金点缀
- 空状态 = 云朵 + 打瞌睡的小猫头鹰 + 一句治愈话术（如"知识云朵还在飘，去写第一篇笔记吧"）
- 首页装饰 = 启明星星座线稿 + 漂浮云朵
- 成就/灵感 = 星尘金闪烁 + 小灯塔发光

## 2 · A区：应用壳（App Shell）

> 业务落点：Electron桌面应用外壳，自定义窗口控制+导航+全局搜索。
> 设计原则：沉浸式侧边栏+奶油色内容区，窗口控制融入标题栏，不突兀。

### I04 · 模态框（Modal）

**视觉**：居中，`--bg-raised`+`--shadow-raise`+`--radius-lg`，遮罩`rgba(92,74,69,.4)`。标题栏（快乐体18px+关闭按钮）+内容区+底部操作栏（左取消/右主按钮）。

**交互**：Esc关闭；点击遮罩关闭（可配置）；打开时焦点第一个输入框。

### I05 · 抽屉（Drawer）

**视觉**：侧边滑出（左/右），`--bg-panel`+对侧`--line`，遮罩同Modal。顶部标题+关闭，内容区滚动。

**动效**：slideIn 300ms `--ease-soft`+遮罩fade。

### I06 · Toast通知

**动效**：入场slideInRight+咕嘟弹入350ms；出场fade+slideRight 200ms；堆叠间距8px。

## 12 · 施工验收规范

### 12.1 全局硬约束（每组件必过）

1. **色彩**：grep全文件`#`字面量，除`:root` token定义处外**零命中**；语义色未当装饰色
2. **字体**：标题/数字用`--font-cute`，正文用`--font-body`，代码用`--font-mono`；数字`tabular-nums`
3. **圆角**：只用`--radius-sm/md/lg/xl/pill`，不写死px
4. **投影**：只用`--shadow-card/shadow-raise/glow/glow-gold`
5. **动效**：只用`--ease-spring/--ease-soft`；`prefers-reduced-motion`全关
6. **状态**：交互组件覆盖hover/active/focus/disabled/选中/loading全态
7. **空态**：列表/卡片区域空状态走I07，不允许空白
8. **响应式**：窄屏（<1024px）不塌不溢出；表格横向滚动；卡片网格`auto-fit minmax(280px,1fr)`
9. **亮/暗**：`data-theme`切换，无硬编码色，双模式各过一遍
10. **性能**：动画只动transform/opacity；长列表虚拟滚动；无内存泄漏（定时器/监听器清理）

### 12.2 组件优先级与施工顺序

**一期必做（🔴，约65个）**：
- 第一批（应用壳+通用，15个）：A01-A04/A06/A08 + I01-I08/I10/I11/I14
- 第二批（首页+任务，21个）：B01-B05/B07-B08 + C01-C03/C05-C10
- 第三批（知识+分身，20个）：D01-D05/D07-D09 + E01-E06/E08/E10
- 第四批（复盘+桌宠+设置，9个）：F01-F04 + G01-G03/G05/G08 + H01/H03-H05

**一期可选（🟡，约22个）**：路演时间充裕时做，不影响核心流程。

**二期规划（🔵，约8个）**：J08雷达图等。

### 12.3 与技术架构的对接

- 组件实现用Vue3 + Element Plus（覆盖样式为奶油糖果token），自定义组件用`<script setup>` + TypeScript
- 通用组件放`frontend/src/components/common/`，业务组件放`modules/<域>/components/`
- 动效用CSS（`@keyframes`+token），复杂动效用GSAP（二期评估）
- 图表用ECharts（自定义主题为奶油糖果色）或手写SVG（简单图表）
- 桌宠独立BrowserWindow，组件放`electron/pet/`
