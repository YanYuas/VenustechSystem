## 第一部分：模块定位与目标

### 1.1 一句话定义

mod-life 是启明星系统的**人生维度模块**，负责把用户分散在各模块中的行为记录，按「身份」这一横切轴聚合为可观察的人生轨迹——我是谁、我在做什么、我成长了多少、我复盘了什么、我沉淀了什么。

### 1.2 模块定位

| 维度 | 内容 |
|------|------|
| 模块类型 | 六维导航之一（life），横切聚合型模块 |
| 核心能力 | 身份管理 + 经历聚合 + 成长追踪 + 复盘系统 + 报告生成 |
| 数据流向 | 只读聚合为主，写入分散在各源模块（任务/日记/文档/分身记忆/项目记忆） |
| 与其他模块关系 | 身份轴是横切标签，挂在 10 张业务表上；经历时间线是四源读取聚合；成长体系由 event_bus 自动结算；复盘数据来源于任务/文档；报告三轴合一 |
| 设计哲学 | 不制造第二份真相。经历视图不建表，报告只读不写，成长由事件驱动自动结算 |

### 1.4 深度优化目标

本模块在三期已完成基础功能闭环。深度优化阶段聚焦三个方向：

1. **身份轴深化**：从简单标签进化为可感知的「人生角色」——多身份切换、身份权重、身份时间线
2. **经历聚合增强**：时间线视图升级、经历标签体系、跨源经历关联
3. **报告模板化**：日报/周报/月报/年报从手动编写进化为模板自动生成

## 第四部分：功能需求详细拆解

### F1. 身份管理深度优化

#### F1.1 身份权重设置

**功能描述**：每个身份新增 `weight` 字段（1-5），表示该身份在用户当前人生中的投入比重。权重在身份列表中以视觉方式体现（权重高的身份圆点更大/位置更靠前），并在经历时间线和报告中影响聚合排序。

**验收标准**：
- [ ] 身份模型新增 `weight` 整数字段，默认 3，范围 1-5
- [ ] 创建身份表单中新增权重选择器（1-5星或滑块），默认选中3
- [ ] 编辑身份弹窗中可修改权重
- [ ] 身份列表按 `(weight DESC, sort_order ASC)` 排序
- [ ] 权重5的身份圆点直径从12px增大到16px，权重1的缩小到8px
- [ ] 经历时间线中，同一日内的多条经历按所属身份权重降序排列
- [ ] 报告身份轴卡片按权重降序排列
- [ ] 权重变更后无需刷新，列表即时重排

**交互细节**：
- 权重选择器使用5颗星，点击第N颗即设为N（与心情评分交互一致）
- 权重变更时列表重排有300ms `--ease-soft` 过渡动画（FLIP技术）
- 权重圆点大小变化同步有200ms缩放过渡
- 编辑弹窗中权重星号hover时预览高亮效果

**状态全覆盖**：
- 默认态：所有身份权重为3，圆点统一12px
- 空状态：无身份时不涉及
- 加载态：权重字段随列表骨架屏占位
- 错误态：权重保存失败时 toast 提示，回退到上次值

#### F1.2 当前身份切换

**功能描述**：在全局顶栏或人生模块顶部新增「当前身份」指示器。用户可快速切换当前活跃身份，切换后影响：经历时间线默认筛选、复盘默认挂接身份、Dashboard 聚焦视图。

**验收标准**：
- [ ] 身份模型新增 `is_current` 布尔字段，每用户最多一个 current=true
- [ ] 前端 useIdentity composable 新增 `currentIdentity` 和 `setCurrent()` 方法
- [ ] 身份管理列表中当前身份有高亮标识（左侧3px主色竖条 + "当前"标签）
- [ ] 点击身份条目右侧操作区的"设为当前"按钮可切换
- [ ] 切换后其他身份的 is_current 自动置 false（后端事务保证）
- [ ] 经历时间线进入时默认筛选为当前身份（而非全部）
- [ ] 复盘撰写弹窗中 identity_id 默认选中当前身份
- [ ] 当前身份切换后 toast 提示"已切换到「XXX」"

**交互细节**：
- "设为当前"按钮使用 `BaseButton variant="pill" size="sm"`，图标 `target`
- 高亮竖条宽度3px，颜色为 `--primary`，圆角右侧 `--radius-sm`
- 当前身份标签使用 `--primary-soft` 背景 + `--primary-ink` 文字
- 切换确认无需二次弹窗（可逆操作，切换回去即可）
- 顶栏当前身份指示器显示为：色点 + 名称，宽度自适应，最大120px省略

**状态全覆盖**：
- 默认态：有一个 current 身份，正常高亮
- 空状态：无任何身份时，顶栏显示"未设置身份"，灰色文字
- 边界态：用户从未设过 current，默认取 sort_order 最小的活跃身份
- 加载态：currentIdentity 加载中时顶栏显示骨架圆点

#### F1.3 身份时间线视图

**功能描述**：在身份管理页点击某身份的"查看时间线"按钮时，跳转到经历页并自动筛选该身份。深度优化后，跳转时同时展示该身份下的任务完成统计、文档数量、最近一条经历摘要，形成单身份全景视图。

**验收标准**：
- [ ] 经历时间线顶部新增「身份概览条」：当筛选为单一身份时显示
- [ ] 概览条包含：身份色点+名称、待办任务数、已完成任务数、文档数、日记数、复盘数
- [ ] 概览条数据来自 report_service 的 _identity_axis 单身份查询
- [ ] 概览条可折叠/展开（默认展开，折叠后只显示色点+名称）
- [ ] 未归类筛选时不显示概览条

**交互细节**：
- 概览条使用 `--bg-inset` 背景，内边距 `--space-3`
- 数字使用 `--text-hi` 粗体，标签使用 `--text-mid` 小号
- 折叠/展开动画：高度从0到auto过渡，300ms `--ease-soft`
- 折叠按钮在概览条右侧，图标 `chevron-up`/`chevron-down`

**状态全覆盖**：
- 默认态：概览条正常展示统计数字
- 空统计态：某维度为0时数字显示"0"，不隐藏
- 加载态：概览条数字显示骨架占位（灰色条）
- 错误态：概览数据加载失败时显示"统计不可用"，不阻塞时间线

### F2. 经历聚合增强

#### F2.1 无限滚动加载

**功能描述**：当前经历时间线只加载第一页50条，滚动到底部时自动加载下一页，实现无限滚动浏览全部历史经历。

**验收标准**：
- [ ] 经历时间线列表滚动到底部距底边 200px 时自动触发加载下一页

- [ ] 已加载全部数据时底部显示"已经到底了"文字（`--text-low`）
- [ ] 加载失败时底部显示"加载失败，点击重试"按钮

### 5.2 新增 API 接口

#### 5.2.1 身份权重与当前身份

```
PATCH /api/v1/identities/{id}/current
  设为当前身份（自动取消其他身份的 current）
  返回: { id, name, is_current: true }

PATCH /api/v1/identities/{id}/weight
  更新身份权重
  Body: { weight: int (1-5) }
  返回: IdentityOut
```

#### 5.2.2 经历标签

```
PUT /api/v1/experience/{source}/{item_id}/tags
  更新某条经历的标签
  Body: { tags: list[str] }
  返回: { id, source, tags }
```

#### 5.2.3 年度报告

```
GET /api/v1/reviews/annual-report?year=2026
  年度复盘报告聚合数据
  返回: {
    year: int,
    total_reviews: int,
    monthly_counts: list[{month: int, count: int}],
    avg_mood: float,
    avg_energy: float,
    best_month: string,
    streak_days: int,
    top_tags: list[{tag: string, count: int}]
  }
```

#### 5.2.4 报告粒度

```
GET /api/v1/report?range=today|week|month|all
  时间粒度报告
  返回: ReportOut（结构同现有，数据按时间范围过滤）
```

## 第八部分：风险与依赖

### 8.1 技术风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 经历标签存储在 JSON 字段中，无法高效 SQL 查询 | 标签过滤需要内存过滤 | 个人数据量千级，内存过滤可接受；数据量万级后再加标签表 |
| 无限滚动导致 DOM 节点过多（千条经历） | 移动端滚动卡顿 | 启用虚拟滚动或限制最多加载500条后提示"请缩小时间范围" |
| 年度报告聚合查询慢 | 年底复盘数据多时加载慢 | 预计算+缓存，或异步生成后存储 |
| 报告粒度切换时重复请求 | 网络请求冗余 | 前端缓存当日/当周/当月数据，切换时先读缓存 |

### 8.2 依赖关系

| 依赖项 | 依赖模块 | 说明 |
|--------|----------|------|
| 任务完成数据 | mod-execution（任务模块） | 复盘自动填充、报告统计依赖任务表 |
| 文档创建数据 | mod-knowledge（知识模块） | 复盘自动填充、档案轴统计依赖文档表 |
| 分身记忆数据 | mod-companion（伙伴模块） | 经历时间线四源之一 |
| 项目记忆数据 | mod-asset（资产模块） | 经历时间线四源之一、档案轴统计 |
| 事件总线 | 全局 event_bus | 成长体系 EXP 结算依赖事件订阅 |
| AI API | 全局 AI 模块 | 复盘反思问题生成依赖 aiApi.reflectionQuestions |
| 设计令牌 | variables.scss | 所有颜色必须使用令牌名 |
| Capacitor 7 | 移动端壳 | 375px 适配需求依赖移动端环境 |
