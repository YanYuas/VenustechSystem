# 启明星系统 — UI 设计规范

> 产品名：启明星系统（源名 **BetterLife AI**）
> 来源：`豆包对话/BetterLife AI（Personal OS）个人操作系统首页深度分析报告.md`（§二 视觉设计深度拆解）
> 用途：前端 1:1 视觉复刻的设计标注 / 设计变量来源
> 日期：2026-08-26

## 1. 整体布局

- **页面结构**：固定左侧边栏（宽约 240px）+ 顶部导航栏（高约 64px）+ 主内容区（自适应宽度）
- **栅格系统**：主内容区 12 列栅格，列间距（gutter）约 20px，页面左右内边距约 24px
- **模块划分与尺寸比例**：

| 区域 | 尺寸 |
|------|------|
| 顶部横幅区 | 高约 220px，通栏 12 列，左主任务信息（约 60% 宽）+ 右任务详情卡（约 40% 宽） |
| 第一行卡片 | 3 列等宽，每卡约 380px，高约 180px |
| 第二行卡片 | 3 列等宽，高约 180px |
| 底部栏 | 3 列等宽，高约 140px |

- **间距规律**：卡片间横向 20px、纵向 20px；卡片内边距统一 20px；模块标题与内容间距 12px

## 2. 色彩系统

| 色彩角色 | 色值 | 使用场景 |
|----------|------|----------|
| 主色（紫） | `#8B5CF6` / `#A78BFA` | 导航高亮、主按钮、图标、进度条 |
| 主色浅底 | `#EDE9FE` / `#F5F3FF` | 卡片图标背景、选中态背景 |
| 辅助粉 | `#F472B6` / `#FCE7F3` | 「生活与自我」模块、爱心图标 |
| 辅助黄 | `#FBBF24` / `#FEF3C7` | 文件夹图标、「当前项目」模块 |
| 辅助蓝 | `#60A5FA` / `#DBEAFE` | 资源中心、工具箱图标 |
| 辅助绿 | `#34D399` / `#D1FAE5` | 进行中状态、成功态 |
| 辅助红 | `#F87171` / `#FEE2E2` | 系统提醒、警告 |
| 中性色-背景 | `#FAFAFC` / 渐变 `#F8F7FF → #FFFFFF` | 页面背景 |
| 中性色-卡片 | `#FFFFFF` / `rgba(255,255,255,0.85)` | 卡片背景（半透明毛玻璃） |
| 中性色-文字主 | `#1F2937` / `#374151` | 标题、正文 |
| 中性色-文字次 | `#6B7280` | 辅助说明、时间标签 |
| 中性色-文字弱 | `#9CA3AF` | 占位符、禁用文字 |

**色彩使用规则**：每个功能模块绑定一个主题色（图标 + 进度条 + 标签），饱和度统一控制在中低水平；主紫色作为全局品牌色贯穿导航和主按钮。

## 3. 字体系统

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| 页面大标题 | 26-28px | 700 (Bold) | 「专注当下，持续创造真实成果」 |
| 页面副标题 | 14px | 400 (Regular) | 「你的人生与项目...」 |
| 卡片标题 | 16px | 600 (Semibold) | 「今日执行」「当前项目」等 |
| 主任务标题 | 18px | 600 | 「完善外贸系统组织架构」 |
| 正文/列表项 | 13-14px | 400 | 待办事项、项目名称、文档名 |
| 辅助文字 | 12px | 400 | 时间标签、数量说明、「查看全部」 |
| 数字标签 | 12-13px | 500 (Medium) | 资源库计数、进度百分比 |
| 按钮文字 | 14px | 500-600 | 「继续工作」「提交成果」 |

**层级关系**：通过字号差（28→18→16→14→12）和字重差（700→600→500→400）建立 5 级清晰层级，行高约 1.5。

## 4. 组件细节

- **按钮**
  - 主按钮（继续工作）：紫色渐变 `#8B5CF6 → #A78BFA`，白色文字，圆角 12px，内边距 10px 24px，hover 轻微上浮 + 阴影加深
  - 次按钮（提交成果）：白底 + 浅紫边框，紫色文字，圆角 12px，内边距 10px 20px

- **输入框（搜索）**：圆角 10px，浅灰背景 `#F3F4F6`，左侧搜索图标，placeholder 浅灰，宽约 280px，高 36px

- **卡片**：白 / 半透明白背景，圆角 16-20px，阴影 `0 2px 12px rgba(139,92,246,0.08)`，hover 加深为 `0 8px 24px rgba(139,92,246,0.12)`

- **进度条**：高 6px，圆角 3px，背景 `#E5E7EB`，填充色为模块主题色（紫/黄/蓝），百分比文字右对齐

- **导航 Tab**：默认灰字 + 线性图标；选中紫字 + 面性图标 + 底部 2px 紫色下划线，padding 8px 16px

- **图标**：20-24px 见方，彩色填充风格，每个图标配浅色圆 / 圆角方背景（如紫色日历图标配 `#EDE9FE` 圆底）

- **复选框**：16px 方形，圆角 4px，未选中白边框，选中紫底 + 白色对勾

## 5. 风格总结

- **整体风格**：治愈系马卡龙风格的 B 端效率工具，融合 Notion 式信息架构与卡通插画的情感化设计
- **视觉质感**：柔和、轻盈、温暖。低饱和配色、大圆角、毛玻璃半透明、轻微弥散阴影 →「无压力」工具氛围
- **设计语言特点**
  - 模块化卡片 + 彩色图标编码，一眼识别功能区
  - 插画作为情感化点缀（兔子、猫咪、植物），非功能性但强化品牌记忆
  - 数据可视化极简（仅进度条 + 数字），不用复杂图表
  - 留白充足，信息多但呼吸感好
