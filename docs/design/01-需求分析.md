# 启明星系统 — 需求分析

> 产品名：启明星系统（源名 **BetterLife AI**，定位 Personal OS 个人操作系统）
> 来源：`豆包对话/BetterLife AI（Personal OS）个人操作系统首页深度分析报告.md`（§一 页面定位 / §三 产品功能分析）
> 日期：2026-08-26

## 1. 产品定位

| 项 | 内容 |
|----|------|
| 产品类型 | AI 驱动的个人知识管理 + 项目管理 + 生活管理一体化操作系统（Personal OS） |
| 品类 | 第二大脑 / 个人效率工具 |
| 核心场景 | 每日打开首页（Dashboard），快速概览当日状态、推进核心任务、进入各功能模块 |
| 页面核心目标 | 一屏内完成「状态感知 → 任务聚焦 → 功能导航」闭环，打开即知今天该做什么 |
| 核心用户需求 | 解决个人在多项目、多角色、多知识来源下的「认知过载」与「执行碎片化」 |
| 目标用户 | 知识工作者、自由职业者、学生、创业者（需同时管理多个项目和大量信息的人群） |
| 业务定位 | 构建「输入 → 处理 → 输出 → 沉淀 → 复用」的个人复利闭环 |

> 一句话：不是单一的待办工具或笔记软件，而是 AI 驱动的个人操作系统，将任务 / 项目 / 知识 / 学习 / 生活 / AI 协作六大能力整合到统一入口。

## 2. 功能模块（业务域）

| 模块 | 功能作用 | 字段规则 | 业务逻辑 |
|------|----------|----------|----------|
| 今日最重要 | 每日单任务聚焦 | 任务名、来源、阶段、进度 %、主任务描述、下一步、状态 | 系统从所有任务中 AI 推荐或用户手动指定 1 个最高优先级任务，强制聚焦 |
| 今日执行 | 当日任务三态分流 | 必须完成 (N)、进行中 (N)、等待处理 (N) | GTD 方法论，按状态分类，点击进入对应列表 |
| 当前项目 | 多项目进度追踪 | 项目名、进度 %、状态标识 | 项目制管理，进度 = 已完成子任务 / 总子任务，按进度降序排列 |
| 资源中心 | 个人知识资产总览 | 7 类库（收集箱 / 领域 / 项目 / 学习 / 知识 / 指令 / 模板）+ 计数 | 所有输入先入收集箱，再分类归档到各库，计数反映资产规模 |
| 学习与成长 | 学习进度量化 | 今日学习 %、学习计划 (N)、知识卡片复习 (N) | 对接学习模块，可能集成间隔重复算法（SM-2）安排复习 |
| 最近沉淀 | 近期产出时间线 | 文档名 + 版本号 + 时间 | 按修改时间倒序，强化「输出」行为的可见性 |
| 生活与自我 | 非工作维度记录 | 家庭 / 健康 / 精力 / 成长四维度 + 一句话 | 每日一句话记录，防止工具沦为纯工作导向 |
| AI 协作小助手 | AI 对话入口 | 对话输入 + 4 场景快捷标签 | AI 作为通用能力层，聊天是临时工作区，不自动持久化（提示「不是记忆库」） |
| 长期资产库 | 可复用资产调用 | SOP / Prompt / Skill / 项目记忆 | 将高频流程、提示词、技能、项目经验结构化沉淀，支持复用 |

**模块关系**：以「今日最重要」为核心焦点；工作 + 学习 + 生活 + 资产四维覆盖。

## 3. 用户路径

### 主路径（每日核心循环）

1. 入口：打开应用 → 首页
2. 感知：查看「今日最重要」任务 + 左侧今日状态
3. 行动：点击「继续工作」→ 进入任务详情 / 工作台
4. 执行：完成子任务 → 勾选待办 → 调用 AI 助手辅助
5. 沉淀：产出文档 → 自动出现在「最近沉淀」
6. 退出：查看「今日完成」计数，获得成就感

### 分支路径

- 新建内容路径：底部快速入口 → 新建笔记 / 项目 / 语音记录
- 知识检索路径：顶部搜索框 → 全局搜索任务 / 项目 / 笔记 / 资源
- 学习路径：学习与成长卡片 → 进入学习中心 → 复习知识卡片
- 资产调用路径：长期资产库 → 选择 SOP / Prompt / Skill → 应用到当前任务

## 4. 设计思路

### 功能排布的产品考量

- 「今日最重要」放视觉焦点（顶部横幅最大区域）：产品核心理念是**「专注」而非「管理」**
- AI 助手放底部常驻：AI 是**辅助工具而非主角**
- 「生活与自我」与工作模块并列：体现**「全人管理」而非「员工管理」**的定位

### 信息优先级

- 时间维度：今日 > 本周 > 长期
- 行动维度：待执行 > 进行中 > 已沉淀

### 隐藏的业务逻辑

- 「收集箱 12」暗示有未分类内容待处理，可引导用户定期整理
- AI 助手明确「聊天是临时工作区，不是记忆库」：产品有独立的记忆 / 知识沉淀机制，避免用户把对话当知识库
- 「项目记忆」作为长期资产一类：每个项目自动积累上下文，可跨项目复用
- 进度条只显示百分比不显示剩余时间：AI 动态预估，避免时间焦虑

## 5. 迭代方向（3 个深度开发方向）

### 方向一：AI 任务自动拆解与日程编排

- 功能：输入大目标 → AI 自动拆解为子任务、估算时长、排入今日 / 本周日程，与「今日最重要」联动，每日自动推荐聚焦任务
- 业务价值：从「任务管理工具」升级为「任务生成 + 管理工具」，降低规划成本，提升 AI 使用深度和付费转化

### 方向二：个人知识图谱与智能关联

- 功能：基于资源中心 7 类库，自动构建实体关系图谱（项目 ↔ 文档 ↔ 知识点 ↔ SOP），打开任务时自动推荐相关历史文档、可复用 SOP 和 Prompt
- 业务价值：真正实现「个人复利」，让沉淀的资产被主动调用而非沉睡，构建数据壁垒和迁移成本

### 方向三：能量管理与节奏建议

- 功能：结合「生活与自我」精力记录和任务完成数据，分析高效时段，自动将高难度任务安排在高效时段，低能量时段安排轻量学习 / 整理，精力低谷时提醒休息
- 业务价值：从「时间管理」升级为「能量管理」，差异化于传统 Todo 工具，提升粘性和健康维度品牌心智
