## 1. 模块定位与目标

### 1.1 模块定位

知识模块是启明星个人操作系统的「第二大脑」承载层，位于六维导航（首页 / 执行 / 知识 / 人生 / 资产 / 伙伴）中的「知识」维度。它把用户日常散落的灵感、笔记、会议纪要、读书摘录、长期沉淀组织成一张可检索、可互联、可回溯的知识网络。

模块由两个子模块构成：

| 子模块 | 前端视图 | 后端入口 | 核心职责 |
|--------|----------|----------|----------|
| 文档管理 | `DocumentExplorerView.vue` + `DocumentEditor.vue` | `/documents` `/folders` | 富文本文档 CRUD、文件夹树、双向链接、版本历史、全文搜索、导出 |
| 资源中心 | `ResourceCenterView.vue` | `/resource` | 收集箱（Inbox）、模板库、领域库 |

### 1.2 模块目标

1. **沉淀闭环**：从收集箱快速捕获 → 整理成文档 → 用双向链接织网 → 在图谱中发现关联，形成「输入 → 处理 → 沉淀 → 复用」闭环。
2. **写作流畅**：编辑器在桌面端达到「打开即写、停止即存」的体验，移动端可用且不丢稿。
3. **可回溯**：每次正文变更自动留快照（上限 10 版），支持与任意历史版本逐行对比并一键恢复。
4. **可视互联**：双链图谱从「有」升级为「好用」——支持缩放、聚焦邻居、点击开文档、识别孤儿文档与悬空链接。
5. **主题无感**：所有新增视觉元素只使用设计令牌，在奶油糖果 / 国风雅集 / 深渊档案 / 史诗典藏四套主题下无需额外适配。

### 1.3 非目标（本期不做）

- 不做多人协作与实时协同编辑（本地优先单机产品）。
- 不做全文向量检索引擎（FTS5 语义搜索留待后续阶段）。
- 不做文档级权限系统（单用户本地应用）。
- 不替换现有编辑器底层为 Tiptap（现状为 textarea + marked，本期在其上做体验增强，不做编辑器内核迁移）。

## 3. 深度优化方向（P0 / P1 / P2 优先级）

### 3.1 优先级定义

| 级别 | 含义 | 交付窗口 |
|------|------|----------|
| P0 | 阻断核心闭环或修复已上线缺陷，必须本期完成 | 本期第一个迭代 |
| P1 | 显著提升体验，本期完成 | 本期第二个迭代 |
| P2 | 增强型能力，本期排期允许则做，否则排入下一期 | 本期第三个迭代或顺延 |

### 3.2 P0（必须完成）

- **P0-1 双链图谱可视化升级**：基于已有 `GET /documents/graph/data`，把 `DocumentGraph.vue` 升级为可缩放、可拖拽、可聚焦邻居、可识别悬空链接与孤儿文档的交互图谱。
- **P0-2 版本对比体验修复**：长文档 diff 性能优化 + 字符级差异高亮 + 对比视图默认折叠相同行。
- **P0-3 收集箱转化真实落地**：`convert_doc` 真正创建文档并把原文写入正文；`convert_task` 真正调用任务服务创建待办。
- **P0-4 移动端编辑器可用性**：375px 宽度下工具栏自适应、抽屉改全屏、双向链接选择器不溢出。

### 3.3 P1（本期完成）

- **P1-1 编辑器分屏实时预览**：编辑 / 预览左右分屏，滚动同步。
- **P1-2 图片粘贴 / 拖拽上传**：支持 Ctrl+V 贴图片、拖拽图片文件到编辑区。
- **P1-3 代码块语法高亮**：marked 渲染时对 ```代码块``` 注入高亮类。
- **P1-4 领域库与文档关联**：文档新增 `domain_id` 字段，领域库可下钻看到归属文档。
- **P1-5 知识关联推荐**：基于标签与文件夹，在编辑器侧栏推荐「可能相关」的 5 篇文档。

### 3.4 P2（排期允许则做）

- **P2-1 搜索增强**：标签权重提升、结果按相关度排序、空结果时给出「按标签新建」引导。
- **P2-2 图谱力导向布局调优**：节点按文件夹着色，鼠标悬停显示字数与更新时间 tooltip。
- **P2-3 版本快照备注**：恢复 / 手动打快照时允许写一句备注，历史列表展示备注。
- **P2-4 文档移动 / 批量操作**：列表支持多选，批量移动文件夹、批量改标签。

## 4. 功能需求详细拆解

> 编号规则：F<模块>.<序号>。每个功能点含「功能描述 / 验收标准（checkbox）/ 交互细节 / 状态全覆盖」。
> 所有颜色一律使用 `variables.scss` 中的令牌名，禁止硬编码 hex。

### 4.1 F1 文档编辑器增强

#### F1.1 自动保存状态条加固（P0）

**功能描述**：在现有三态（保存中 / 未保存 / 已保存）基础上，新增「保存失败」第四态，并在网络异常时提供手动重试入口。现有自动保存参数（防抖 1000ms、兜底 30s）保持不变。

**验收标准**：
- [ ] 保存请求返回非 2xx 时，状态条显示红色「保存失败 · 点击重试」，文字使用 `--straw-ink`。
- [ ] 连续失败 3 次后，状态条右侧追加「离线草稿已暂存到本地」副文案（使用 `--butter-ink`）。
- [ ] 点击失败态文字触发手动 `save()`，成功后回到「已保存 HH:MM」态。
- [ ] 页面隐藏（`visibilitychange` 到 hidden）时强制触发一次保存，不等待防抖。
- [ ] 卸载前（`beforeunload`）若 `dirty === true`，浏览器弹出原生离开确认。

**交互细节**：
- 状态条切换为 150ms `--ease-soft` 过渡；失败态图标为 `AppIcon name="warn"`，带 1s 呼吸动画（opacity 0.6↔1.0）。
- 失败态按钮 hover 时背景使用 `--straw-soft`，圆角 `--radius-pill`，padding `4px 12px`。

**状态全覆盖**：
- 默认态：`--mint-ink` 对勾图标 + 「已保存 HH:MM」。
- 未保存态：`--gold` 圆点 + 「未保存」。
- 保存中态：`AppIcon name="spin"` 旋转 1s/圈 + 「保存中…」。
- 错误态：`--straw-ink` 警示图标 + 「保存失败 · 点击重试」。

#### F1.2 分屏实时预览（P1）

**功能描述**：在现有「编辑 / 预览 / 阅读」三模式之上，新增第四种模式「分屏」。左侧 textarea 编辑，右侧实时渲染 Markdown，两栏滚动同步。

**验收标准**：
- [ ] 模式切换按钮组新增「分屏」按钮，与现有三个按钮同高同圆角。
- [ ] 分屏下左栏占 50%、右栏占 50%，中间以 `--line` 1px 分隔；最小容器宽度 < 768px 时自动降级为单栏预览。
- [ ] 左栏滚动时，右栏按「当前可视行占全文比例」同步滚动位置（用 `requestAnimationFrame` 节流，间隔 ≥ 16ms）。
- [ ] 输入后右栏渲染延迟 ≤ 300ms（marked 同步解析，内容 > 50KB 时启用 200ms 防抖再渲染）。
- [ ] 分屏模式下双向链接选择器仍可正常弹出，不被右栏遮挡。

**交互细节**：
- 分屏切换为 200ms `--ease-soft` 横向展开（右栏从 translateX(20px) + opacity 0 入场）。
- 两栏之间拖拽分隔条可调整宽度（40%–60%），拖动时 cursor 变为 `col-resize`，松手后宽度写入 localStorage。

**状态全覆盖**：
- 默认态：左栏光标闪烁，右栏渲染当前内容。

### 6.1 新增 / 修改字段

| 表 | 字段 | 类型 | 说明 | 优先级 |
|----|------|------|------|--------|

### 6.2 API 变更

| 方法 | 路径 | 变更 | 说明 |
|------|------|------|------|
| POST | `/resource/inbox/{id}/process` | 行为变更 | `convert_doc` 真正创建文档；`convert_task` 真正创建任务；返回体增加 `converted_id` |
| PATCH | `/documents/{id}` | 请求体新增 `domain_id` | 与 `identity_id` 同构，None 解除关联 |
| GET | `/documents/graph/data` | 响应 nodes 增加 `color_hint`（按文件夹预分配色板索引） | 前端可直接取色，无需自算 |

### 6.3 Alembic 迁移要求

- 新增列必须 `nullable=True`，不写默认值（SQLite 兼容）。
- `documents.domain_id` 加索引（`ix_documents_domain_id`）。
- 迁移脚本必须可回滚（downgrade 完整）。

### 6.4 性能约束

- `graph` 接口在文档数 ≤ 500 时响应 ≤ 300ms；> 500 时仅返回有链接的节点。
- diff 接口（若后端承担）单次处理 ≤ 200KB 文本，超时 5s。
- 全文搜索 `LIKE %kw%` 在 `documents.content`（Text）上全表扫，文档数 > 2000 时必须引入 FTS5（本期仅预留，不实施）。

## 9. 风险与依赖

### 9.1 风险

| 编号 | 风险 | 等级 | 缓解措施 |
|------|------|------|----------|
| R1 | 图谱 Canvas 渲染在低端 Android 机上掉帧 | 中 | 节点 > 200 时降级为静态 SVG；提供「简化图谱」开关 |
| R2 | Web Worker diff 引入打包复杂度 | 低 | 用 Vite `?worker` 语法，不引入额外依赖 |
| R3 | 收集箱转任务依赖任务模块接口，跨模块联调风险 | 中 | 本期先定义 TaskService 最小接口（create），联调排前 |
| R4 | 编辑器不上 Tiptap，长期可能落后生态 | 低 | 本期不迁移，记录技术债；P2 后再评估 |
| R5 | SQLite FTS5 未启用，搜索性能随文档数下降 | 中 | 本期仅监控，文档数 > 2000 时报警 |

### 9.2 依赖

- **任务模块（mod-execution）**：`convert_task` 需要调用 TaskService.create。
- **分身模块（mod-companion）**：快速捕获成功后桌宠气泡确认事件。
- **全局设计令牌**：所有新增视觉必须在 `variables.scss` 既有令牌内，不新增色值。
- **Capacitor 7 壳**：移动端手势与键盘弹起行为依赖壳层版本。

### 9.3 技术债记录

- 现状编辑器为 textarea + marked，非富文本 WYSIWYG；若二期需要真正的富文本（拖拽块、表格、公式），需独立立项迁移 Tiptap，不在本期范围。
- 全文搜索为 `LIKE %kw%`，无中文分词；FTS5 迁移需 Alembic 重建虚拟表，排期另议。
