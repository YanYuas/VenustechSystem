## 2. 操作流程

### 核心任务流程（完成今日最重要任务）

1. 首页看到「完善外贸系统组织架构」任务卡
2. 阅读「下一步」：完成部门职责说明书初稿
3. 点击「继续工作」→ 进入任务执行界面
4. 执行中如需辅助 → 返回首页点击 AI 助手「开始对话」或「写作助手」
5. 完成后 → 点击「提交成果」→ 填写成果说明 → 提交
6. 任务状态更新，进度条推进，出现在「最近沉淀」

### 异常情况处理

- 任务无法继续：无明显「阻塞/卡壳」反馈入口，用户需手动修改状态
- 今日最重要任务选错：无明显「更换今日任务」按钮，可能需长按或进入任务页设置
- 待办事项过多：左侧仅显示 4 条，无「展开更多」，需进入「今日执行」查看全部

## 3. 状态设计

| 状态 | 表现 |
|------|------|
| 默认态 | 所有卡片正常展示，导航「首页」高亮，待办未勾选，进度条按实际百分比填充 |
| Hover 态 | 卡片阴影加深、轻微上浮；按钮颜色加深；链接文字变色；图标轻微放大 |
| 加载态 | 推测为骨架屏（卡片区域灰色占位），截图中未展示 |
| 空状态 | 如无进行中项目，「当前项目」卡片应显示空状态插画 +「新建项目」按钮（未展示） |
| 完成态 | 待办勾选后文字删除线 + 变灰；任务 100% 后进度条变绿，「继续工作」变「已完成」 |
| 错误态 | 推测为网络错误时卡片显示重试按钮（未展示） |
| 专注态 | 无明显「专注模式/勿扰」状态切换 |

## 4. 体验亮点与问题

### 亮点

- 「今日最重要」单任务卡：将「选择做什么」决策成本降为零，打开即行动
- 左侧边栏「今日状态」数字计数（必须完成 2 项、进行中 3 项）提供全局掌控感
- AI 助手 4 个快捷标签（头脑风暴/任务拆解/写作助手/知识问答）精准覆盖高频场景，降低 AI 使用门槛
- 底部快速入口将「新建」操作前置，无需进入模块即可快速记录
- 「最近沉淀」按时间展示产出，给用户持续正反馈

### 问题

- **首屏信息过载**：1 横幅 + 6 卡片 + 3 底部栏 + 左侧 4 区域，新用户认知负担重
- **左侧待办无展开入口**：仅 4 条，超过无法在首页操作，必须跳转
- **主任务卡插画干扰**：兔子看山插画占卡片约 40% 面积，与任务信息并列，分散注意力
- **缺少快捷操作**：待办无右键菜单、无拖拽排序、无快速编辑入口
- **进度不可交互**：进度条仅展示，无法点击直接更新进度
- **AI 助手位置偏下**：核心差异化功能放页面最底部，首屏被截断，需滚动才能看到
- **无键盘快捷键提示**：搜索框有 ⌘K 提示，但其他操作无快捷键引导

## 5. 交互优化建议

1. **首页自定义布局**：允许拖拽调整卡片顺序、折叠不常用模块（如「生活与自我」可收起），降低信息过载
2. **左侧待办滚动/展开**：超过 4 条显示「展开」按钮，或允许侧边栏区域独立滚动，避免跳转打断心流
3. **主任务卡专注模式**：点击「继续工作」进入全屏专注模式（隐藏其他模块、显示番茄钟、AI 助手侧边栏），强化「专注当下」主张
4. **待办快捷操作**：hover 显示编辑/删除/优先级图标，支持拖拽排序，右键菜单支持「转化为项目」「添加到今日最重要」
5. **AI 助手上移/悬浮**：设为右下角悬浮按钮（类似 ChatGPT 侧边栏），任意位置可唤起
6. **进度条可交互**：点击进度条弹出「更新进度」滑块，或直接点击百分比快速标记阶段
7. **完成动效**：勾选待办或任务完成时触发轻微庆祝动效（彩屑、插画角色表情变化），强化成就感
8. **补空状态设计**：各模块无数据时展示引导性空状态（如「还没有项目，点击新建第一个项目」），降低冷启动门槛
