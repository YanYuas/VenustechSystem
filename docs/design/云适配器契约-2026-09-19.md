# 云同步适配器契约（F2.5 · 冻结版）

> 2026-09-19 · 对应 `backend/app/core/sync_adapters.py`
> 状态：**契约已冻结**；本地目录实现已就位，云实现待接入。

## 为什么先冻契约

二期 PRD v2.0 明确"云端同步不做，放三期"。但**契约可以先冻**——将来接
对象存储 / WebDAV / 自建服务时，只要新实现满足本契约，`SyncEngine`、
前端、迁移脚本、测试全部不用改。

## 契约（四个方法，不可增删语义）

| 方法 | 语义 | 幂等性要求 |
|---|---|---|
| `push(payload: bytes, key: str) -> RemoteObject` | 写入一个同步包 | **必须幂等**：同 key 重复 push 为覆盖写，不得产生重复对象 |
| `pull(key: str) -> bytes` | 读取同步包原始字节 | key 不存在时抛 `KeyError` |
| `list_objects() -> list[RemoteObject]` | 列出全部包，按 modified_at 倒序 | 只读 |
| `delete(key: str) -> bool` | 删除包，返回是否真的删了 | 幂等：删不存在的 key 返回 `False` 而不报错 |

`RemoteObject` 字段固定：`key / size / modified_at(ISO8601) / user_id`。

## 四条硬约束

1. **适配器只搬运字节**：diff / 合并 / 冲突解决是 `SyncEngine` 的职责，
   适配器不得理解包内结构（除读取 `user_id` 用于展示）
2. **不得改写包内容**：包一旦生成即为不可变对象；云实现若做了加密/压缩，
   必须在 `push`/`pull` 内部对称处理，对上层透明
3. **不得访问业务库**：适配器必须无状态、可单独单测（传一个假 payload 即可测）
4. **不得假设包大小**：实现需支持流式或分片（包可能达 100MB 级）

## 安全边界（与 F7.2 一致）

- 包内已含 `MANIFEST.json`（SHA256 清单）与 `user_id`
- 云实现**必须**在 `pull` 后由上层跑 `verify`，校验和不符即拒绝
- 适配器自身不做鉴权判定：凭据由实现内部持有，**不得写入日志**

## 接入清单（未来接云时按此走）

1. 新建实现类（如 `S3Adapter`），`class S3Adapter(SyncAdapter)`
2. `register_adapter("s3", S3Adapter)`
3. 在设置页新增适配器选择项（`sync.adapter` 配置键，默认 `local-dir`）
4. 冒烟新增：push → list → pull 往返一致、delete 幂等、重复 push 不重复
5. 同步策略（SYNC_POLICY 四级）保持不变——它是包的内部语义，与传输无关
