## D 保险箱详录（2026-09-16，8ab58ab / 519b55b）

### D0：修硬编码 salt（总路线标红前置，先行完成）

`core/encryption.py` 原来在 `master_key` 路径用**硬编码全局 salt**
（`venustech_system_salt_2026`）派生密钥 —— 相同密码跨用户派生出
相同密钥、彩虹表可跨库复用。改为：
- `derive_key(password, salt)` 显式收 salt，`new_salt()` 随机 16 字节
- master_key 路径的 salt 持久化在密钥文件旁（0o600）
- PBKDF2 迭代 100k → 200k；**顺带修 InvalidToken 未导入的 NameError**
  （decrypt 的异常分支从未真正生效）
- `cryptography` 从可选升级为硬依赖（requirements.txt）

### 保险箱设计（本期核心）

- **主密码不落盘**：`vault_config` 只存随机 salt + 校验器（派生密钥
  加密的已知常量）。解锁 = 解密校验器 —— 验证与取密钥一条机制，
  没有可离线爆破的第二份哈希
- **解锁态 = 工作密钥的进程内缓存**，服务重启自动上锁；主密码任何
  时刻不落盘、不常驻
- **明文唯一出口**：`GET /vault/items/{id}/secret`，要求解锁态，
  记录 last_accessed_at；列表响应不含密文与明文字段
- **换主密码** = 旧密钥解密全部凭据 + 新随机 salt 重加密（冒烟
  验证轮换后明文可读）
- 凭据可挂 identity_id（横切轴延伸）；SYNC_POLICY 引擎落地时按
  D11/A 只同步密文
- 0017 迁移（幂等守卫）：vault_config / vault_items，带同步 Mixin

### 前端（519b55b）

`/vault`（hidden，入口在设置页「高级设置」）按状态机呈现：
未初始化 → 创建主密码（两次确认）；未解锁 → 解锁表单；

## S6-3b diff-sync 引擎详录（2026-09-16，4f18dd3）—— P0 完成

「云同步从 0 变成 1」的地基。P0 按总路线只做**抽象层 + 本地适配器**
（JSON 同步包导出/导入），云适配器将来实现同一契约，引擎零改动。

### SYNC_POLICY 表分级（R2 铁律：第一天就有）

| 策略 | 表 | 语义 |
|---|---|---|
| full | 其余 44 张 | 正常 diff-sync |
| derived-skip | workspace_files | 派生数据不同步（重扫即得，量大） |
| encrypted-only | vault_items / vault_config | 列白名单：剥明文 notes，只同步密文材料 |
| filtered | settings | workspace.* 设备键整行排除，不跨机 |

新增表默认 full；特殊表在 SYNC_POLICY 注册表登记即可。

### 引擎行为

- canon（datetime→ISO）/ snapshot / diff 三态 / apply（upsert）
- **LWW（最后写入胜）+ 只增不删**：远端没有的行不动本地；软删行随行同步
- `resolve_conflict()` 预留接口（当前 LWW）—— 诚实边界：无真正冲突
  解决，将来可替换为字段级合并
- 包绑定 user_id 防串包；50MB 上限；版本号校验

### 验收（二期 W4 基准，全落断言）

- **双库往返一致**：硬删一行 → 导入恢复 → 内容一致
- **二次 apply 零操作**：同一包重复导入 ops==0
- 分级生效：派生表缺席包 / vault 剥明文 / 设备键排除
- LWW：本地较新 → 导入旧包零操作

冒烟 121 → **133**（+12）。同步 UI（设置页导入导出按钮）随 E0/S6-6
一并做 —— 引擎层优先。
