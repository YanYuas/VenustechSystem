## 三、设计侧必须遵守的 7 条硬约束

1. **设计令牌唯一来源**：`frontend/src/styles/variables.scss`。组件文件内不允许出现 hex 色值（`python scripts/audit_hardcoded_colors.py` 基线 **171 处 / 16 文件**，只允许减不允许增）
2. **组件全自研**：项目禁用 Element Plus 全量引入（复杂组件可按需），基础组件在 `src/components/common/`
3. **六维导航不可改结构**：维度与二级 Tab 定义在 `constants/dimensions.ts`，页面路由在 `src/app/router/index.ts`；新增页面需同时登记两处
4. **移动端适配靠 `<768px` 媒体查询**：`global.scss` 已有全局兜底层（栅格塌缩/防横溢），**逐页适配时不要写死宽度**，优先用 token 与 grid 自动流
5. **前端不写业务逻辑到 API 层之外**：数据流 `Views → Composables → API`，API 层是后端唯一入口
6. **不碰后端**：涉及数据/接口变更请找我或先提需求（四层分层 api→service→repository→model 有架构守护测试）
7. **改完必须跑**：`python scripts/check_all.py`；前端样式改动后额外确认 375px 宽无横向溢出

## 六、本机环境坑（省你踩坑的时间）

- **Bash 工具 PATH 缺 `/usr/bin:/bin`**：每条命令前加 `export PATH="/usr/bin:/bin:$PATH"`
- **PowerShell 工具不回显 stdout**：结果 `Out-File` 到工作区再用读文件工具看
- **仓库 `.git` 是 junction**：真身在 `C:\Users\21722\qimingxing-git-repo`（为避开同步客户端回滚），工作树里是链接
- **同步客户端会锁 SQLite**：冒烟/探针数据目录必须用 `%TEMP%`，不要在仓库目录建测试库
- **GitHub 网络不稳**：推送可能连续超时，用「推送模块分支.bat」重跑即可
