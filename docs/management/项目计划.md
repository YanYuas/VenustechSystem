### 后端骨架 v0.1 交付清单

- **工程**：FastAPI + SQLAlchemy 2.0 + SQLite(WAL/StaticPool) + Alembic（启动自动迁移）+ pydantic-settings + loguru，零 pip 安装（依赖已装）
- **分层**：`api → services → repositories → models` 严格单向，核心 infra（统一响应/异常/事件总线/DPAPI 降级）
- **数据模型**：11 表对齐 PRD §15（UUID 主键 / 时间戳 / deleted_at 预留 / snake_case / is_focus 互斥部分唯一索引）
- **契约**：统一响应 `{code,message,data,timestamp}`，错误码 1001/1002/3001/4001/5000，字段与前端 8 个 types 文件严格一致
- **全模块路由**：health/auth/task/folder/document/conversation/review/dashboard/backup 全部接线且功能可用（含 SSE 流式对话、版本历史、双向链接、全局搜索、状态机校验）
- **AI 降级**：LLMClient 抽象（httpx DeepSeek / 未配 Key 时 Mock），Prompt 集中管理
- **验证**：`scripts/smoke_backend.py` 28 项 TestClient 断言全绿 + 真实 uvicorn HTTP 200 + 架构守护测试（tests/ 待 pytest）
- **演示种子**：PRD §36.2 预设数据（5任务/5文档/3文件夹/6复盘/1对话）首次启动自动灌入

### 前端骨架 v1.0 交付清单

- **工程**：Vite + Vue3 + TS 严格模式 + Pinia + Router(Hash) + SCSS，禁 axios（原生 fetch）/禁 VueUse（自研）
- **分层**：`Views → Components → Composables → API` 单向数据流，API 层为后端唯一入口
- **API 层**：7 模块（auth/task/document/conversation/review/dashboard/backup）+ `http.ts`（15s超时/重试1次/参数清洗/SSE流式）
- **类型系统**：8 文件（api/common/user/task/document/conversation/review/dashboard），字段与后端 snake_case 一致
- **Composables**：useAsync/useTask/useDocument/useConversation/useReview/useDashboard/useAutoSave/useOnline + toast/modal/theme/shortcuts
- **主题**：CSS 变量 + data-theme，三套主题×明暗（奶油糖果默认/国风雅集/深渊档案）
- **组件**：common 基础件(I01-I10+) + layout 应用壳(A01-A05) 全自研；复杂组件走 Element Plus 覆盖
- **基建**：constants / directives / errorHandler / 路由恢复 / 全局快捷键

## 总体策略

- **纵向切片**：不做「先写完所有后端再写前端」，而是一个功能模块前后端一起跑通，再做下一个
- **MVP 聚焦核心闭环**：2 周看到可用产品，避免完美主义
- **AI 代码生成**：用 AI 根据数据模型生成 CRUD 骨架代码，只做业务逻辑调整

## 阶段一：MVP 核心闭环（第 1-2 周）

**目标**：跑通「注册登录 → 首页仪表盘 → 任务管理 → AI 对话」核心链路

| 优先级 | 功能 | 后端 | 前端 |
|--------|------|------|------|
| P0 | 用户注册/登录/JWT | auth 模块 | Login/Register 页 |
| P0 | 首页仪表盘聚合接口 | dashboard 模块 | Dashboard 布局 + 6 个卡片骨架 |
| P0 | 任务 CRUD + 今日聚焦 | task 模块 | 侧边栏待办 + 任务卡片 |
| P0 | 项目 CRUD + 进度 | project 模块 | 项目卡片 + 进度条 |
| P0 | AI 对话（流式） | ai 模块 + conversation | 右侧抽屉对话窗口 |
| P1 | 文档/笔记 CRUD | document 模块 | 最近沉淀卡片 |
| P1 | Prompt 模板管理 | prompts 模块 | 快捷标签 + 模板选择 |

**交付标准**：能登录、能建任务、能设今日聚焦、能和 AI 流式对话、首页数据真实展示。

## 单人开发效率建议

1. **代码生成**：用 AI 根据数据模型生成 CRUD 骨架代码（FastAPI 的 router/schema/model + Vue 的 api/types/views），只做业务逻辑调整
2. **Mock 方案**：后端接口未完成时，前端用 `msw` 或 `mockjs` 拦截请求，前后端并行开发
3. **纵向切片**：功能模块前后端一起跑通，再做下一个
4. **UI 组件复用**：Element Plus 覆盖 80% 组件，自定义组件控制在 20% 以内
5. **数据库迁移**：开发期频繁改表，用 `alembic revision --autogenerate` 自动生成迁移，不手写 SQL
