# M01 Dashboard 首页深度开发PRD

> 分支：`feature/dashboard-deep` | 优先级：P0 | 预计工时：3天

## 一、模块定位

Dashboard是启明星系统的入口页面，承担"个人OS桌面"的角色。用户打开应用首先看到此页，需要在一屏内获取今日核心信息并快速进入各功能模块。

**核心目标**：信息聚合 + 快速操作 + 情感激励

## 二、当前实现状态

### 已实现
- 焦点任务卡（B01）：显示今日最重要任务，含进度条
- 统计卡组（B02）：任务/文档/对话/复盘四项统计
- 快捷入口宫格（B03）：6个模块快捷入口
- 最近文档列表（B04）：最近编辑的5篇文档
- 灵感气泡卡（B05）：随机灵感/名言展示

### 未实现/待完善

- 项目模块入口与项目概览卡
- 灰度显示待开发模块
- 本周进度环（B06）
- 连续打卡徽章（B09）

## 三、深度开发功能清单

### P0 必须完成

#### F01 首页一屏自适应布局
- **需求**：浏览器全屏时所有模块在一屏内装下，无需页面滚动
- **实现**：
  - 首页使用CSS Grid + minmax()自适应
  - 卡片内容过多时启用卡片内部滚动（overflow-y:auto）
  - 左侧信息面板固定高度，内部区域独立滚动
  - 顶部导航固定，内容区calc(100vh - 56px)
- **验收**：1920x1080屏幕下，首页无页面级滚动条

#### F02 项目模块入口与概览
- **需求**：首页展示项目模块入口，点击进入项目列表
- **实现**：
  - 快捷入口宫格新增"项目"入口（第7个）
  - 新增"进行中项目"横向滚动卡，显示前3个项目
  - 项目卡显示：名称、进度条、任务数、截止日期
  - 点击项目卡直接进入项目详情
- **数据契约**：`Project{id,name,color,progress,task_count,due_date}`

#### F03 灰度待开发模块
- **需求**：未实现的模块在首页显示为灰度状态，标注"待开发"
- **实现**：
  - 快捷入口中未实现模块：opacity:0.4 + "待开发"角标
  - 点击时Toast提示"该模块正在开发中，敬请期待"
  - 当前已实现：首页/今天/项目/学习/工作台/复盘
  - 待开发模块：财务/健康/社交/插件市场等（二期）

### P1 高质量打磨

#### F04 本周进度环
- **需求**：展示本周任务完成进度的环形图
- **实现**：SVG环形进度，中心显示完成率，下方显示"已完成X/Y"
- **数据来源**：本周（周一至周日）任务完成数/总数

#### F05 连续打卡徽章
- **需求**：显示连续复盘/使用天数，激励用户持续使用
- **实现**：火焰图标 + 连续天数 + 本周打卡点（7个圆点）
- **数据来源**：review表中按日期统计连续天数

#### F06 今日待办速览
- **需求**：首页快速查看今日待办，支持勾选完成
- **实现**：
  - 显示今日截止的5个任务
  - 支持一键勾选完成（乐观更新）
  - 完成后显示动画反馈
  - "查看全部"链接跳转到任务页

#### F07 首页英雄区
- **需求**：顶部展示个性化问候与今日一句话
- **实现**：
  - 根据时间显示问候（早上好/下午好/晚上好）
  - 每日一句励志名言（本地词库，可AI生成）
  - 当前日期与星期
  - 渐变背景 + 装饰元素

### P2 二期预研

#### F09 小部件市场

## 四、技术实现要点

### 前端
- `DashboardView.vue`重构为组件化布局
- 新增组件：`ProjectOverviewCard.vue`、`WeekProgressRing.vue`、`StreakBadge.vue`、`TodayTodoList.vue`、`HeroSection.vue`
- 使用`useDashboard` composable获取聚合数据
- 响应式断点：≥1440px三列，≥1024px两列，<1024px单列

### 后端
- `dashboard_service.py`扩展：
  - `get_projects_overview()`：获取进行中项目概览
  - `get_week_progress()`：本周任务完成统计
  - `get_streak_data()`：连续打卡数据
  - `get_today_todos()`：今日待办列表
- API：`GET /api/v1/dashboard/overview` 返回聚合数据

### 性能
- 首页数据单次请求聚合，避免多次API调用
- 卡片懒加载：视口外的卡片延迟渲染
- 统计数据缓存5分钟

## 五、数据模型扩展

无需新增表，复用现有：
- `tasks`：今日待办、本周进度
- `documents`：最近文档
- `projects`：项目概览
- `reviews`：连续打卡

新增缓存表（可选）：
```sql
CREATE TABLE dashboard_cache (
  id TEXT PRIMARY KEY,
  user_id TEXT NOT NULL,
  data_json TEXT NOT NULL,
  updated_at DATETIME NOT NULL
);
```

## 六、API接口设计

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/dashboard/overview` | 首页聚合数据（含项目/进度/打卡） |
| GET | `/api/v1/dashboard/inspiration` | 获取每日灵感 |
| POST | `/api/v1/dashboard/todo/{id}/toggle` | 快速切换待办状态 |

## 七、验收标准

1. 1920x1080屏幕下首页无页面滚动条
2. 所有已实现模块可正常跳转
3. 待开发模块显示灰度状态与提示
4. 项目概览卡显示正确数据
5. 今日待办可快速勾选完成
6. 数据加载时间<500ms
7. 四套主题下首页显示正常

## 八、风险与依赖

- **依赖**：M06 Project模块需先提供项目概览API
- **风险**：首页数据聚合可能导致API响应慢，需缓存优化
- **兼容性**：小屏幕下布局可能溢出，需响应式处理
